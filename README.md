# Telkom University Company Profile - Praktikum

Project simulasi HTML, CSS, PHP native, MySQL/MariaDB, dan Git

Perubahan ini dibuat dari simulasi Laptop B

Langkah langkah menjalankan project

1. Pastikan folder praktikum terdapat di htdocs (XAMPP) atau WWW(Laragon)
2. Nyalakan MySQL dan Apache
3. Buka http://localhost/telkom-company-profile/index.php pada browser
